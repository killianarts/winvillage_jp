I learned how to make a complex query using ModelChoiceField. I also
learned how to provide a form object some arbitrary parameter.

```python
class RoomChoiceForm(forms.Form):
    rooms = forms.ModelMultipleChoiceField(queryset=None)

    def __init__(self, *args, **kwargs):
        number_of_adults = kwargs.pop("number_of_adults")
        super(RoomChoiceForm, self).__init__(*args, **kwargs)
        self.fields["rooms"].queryset = Room.objects.filter(
            pricing_tiers__number_of_adults=number_of_adults
        )
```
